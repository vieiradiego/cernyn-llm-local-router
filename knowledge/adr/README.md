# ADRs — decisões de arquitetura

Uma decisão por arquivo: `NNN-<slug>.md`. Capturadas das sessões com Fable/Opus quando
uma escolha estrutural é feita (biblioteca, padrão, fronteira de módulo).

Formato mínimo:

    # NNN — <decisão em uma frase>
    Data: AAAA-MM-DD · Projeto: <repo> · Status: ativa | substituída por NNN
    ## Contexto
    ## Decisão
    ## Consequências (o que o executor precisa respeitar)

Indexadas pelo MCP knowledge-server — o executor as encontra via search_knowledge.
